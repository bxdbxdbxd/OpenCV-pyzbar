# OpenCV-pyzbar

# Файл ver7.py

1. **Предварительная адаптация снимков**: автоматическое разделение книжных/документных разворотов (получение одной страницы из двустраничного скана).
2. **Сегментация макета**: поиск и вырезание верхней шапки/заголовка документа с помощью морфологического анализа OpenCV.
3. **Очистка изображения**: авто-удаление бланковых горизонтальных линий и отсечение пустых белых полей (кроп по контенту).
4. **Локальный OCR-анализ**: выделение информативной зоны (верхние 25% остатка), поиск отдельных текстовых блоков и их распознавание через Tesseract OCR.
5. **Визуальный контроль**: вывод всех шагов обработки в 4-канальном интерфейсе и формирование интерактивной галереи найденных фрагментов с распознанным текстом.

## Алгоритм работы
1. **Кадрирование разворота**: Если ширина загруженного изображения превышает высоту, программа считает его разворотом с дублированием макета и автоматически забирает в работу только левую половину.
2. **Сегментация верхнего блока**:
   * Перевод изображения в оттенки серого и бинаризация методом Оцу (`THRESH_OTSU`).
   * Морфологическое закрытие (`MORPH_CLOSE`) с настраиваемыми ядрами `X` и `Y` для объединения букв и строк в единую область.
   * Выделение контуров и выбор самого верхнего блока, превышающего заданную минимальную площадь.
3. **Очистка остатка**:
   * Под верхним блоком вырезается оставшаяся часть страницы.
   * `remove_horizontal_lines`: удаление горизонтальных линий с помощью морфологического открытия длинным прямоугольным ядром.
   * `trim_white_borders`: отсечение пустых белых полей по краям на основе бинарной маски.
4. **Поиск и распознавание текста (OCR)**:
   * Из очищенной зоны берется верхний срез высотой в 25%.
   * С помощью дилатации (`dilate`) близкие символы объединяются в отдельные слова/строки.
   * Каждый выделенный фрагмент передается в `pytesseract` (язык: `eng`, режим PSM: `6`).
5. **Отображение результатов**: Результаты визуализируются в 4 предпросмотрах, а найденные карточки с OCR-текстом высылаются в нижнюю горизонтальную галерею.

# Файл main.py

Приложение решает задачу автоматического обнаружения и считывания штрихкодов на снимках и сканах с низким контрастом или сложным фоном. Основные функции:

1. **Локализация штрихкода (ROI)**: Поиск области с характерной вертикальной градиентной текстурой полос штрихкода с помощью операторов Собеля и морфологической обработки OpenCV.
2. **Фокусировка и кадрирование**: Вырезание найденного фрагмента (Region of Interest) с небольшим отступом (padding) для улучшения качества распознавания.
3. **Декодирование данных**: Расшифровка текста и определение типа штрихкода через `pyzbar`.
4. **Резервный поиск**: Если вырезанная область не распозналась, алгоритм делает повторную попытку декодирования по всему исходному изображению.
5. **Визуализация результатов**: Отрисовка зеленой рамки вокруг найденного штрихкода и вывод декодированных данных в графическом интерфейсе Tkinter.

## Алгоритм работы
1. **Выделение градиента полос**:
   * Изображение переводится в оттенки серого.
   * Вычисляется разница горизонтального и вертикального операторов Собеля (`Sobel(dx=1) - Sobel(dy=1)`). Это подчеркивает области с высокими вертикальными контрастными изменениями (черно-белые полосы) и убирает однородный фон.
2. **Морфологическая сборка**:
   * Применяется размытие (`cv2.blur`) и бинаризация методом Оцу (`THRESH_OTSU`).
   * С помощью прямоугольного ядра `(21, 7)` выполняется морфологическое закрытие (`MORPH_CLOSE`), чтобы слить отдельные вертикальные полоски в единый сплошной прямоугольный блок.
   * Выполняется последовательная эрозия и дилатация (`erode` / `dilate`) для удаления мелкого графического шума.
3. **Поиск наибольшего контура**:
   * Среди найденных контуров выбирается самый крупный — потенциальная зона штрихкода.
   * Рассчитываются координаты Bounding Box с добавлением отступа в 15px со всех сторон.
4. **Декодирование (pyzbar)**:
   * Сначала `pyzbar.decode` натравливается исключительно на вырезанный фрагмент (ROI).
   * **Fallback**: Если локальный поиск не дал результата, выполняется повторная попытка декодирования всего исходного изображения.
5. **Отображение в GUI**:
   * На исходном изображении рисуется зеленая рамка вокруг найденного штрихкода.
   * Картинка масштабируется под окно приложения.
   * В текстовое поле снизу выводится список найденных штрихкодов с указанием типа (EAN13, Code128, QR и т.д.) и их текстового значения.
